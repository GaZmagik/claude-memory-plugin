# Context-file graph nodes — key decisions

_Thinking document created 2026-02-18T21:37:09.278Z_

## Thoughts

### 2026-02-18T21:37:21.448Z - Thought
Use new MemoryType.ContextFile = 'context-file' — NOT hub. Hub nodes are user-writable, context-file nodes are read-only external files owned by the Claude CLI. Distinct type enables write guards, distinct sync path, distinct mermaid rendering, and type-filtered commands without ambiguity.

### 2026-02-18T21:37:21.763Z - Thought
Two new IndexEntry optional fields: contextFileKind ('claude-instructions' | 'agent-definition' | 'agent-memory-summary') and externalPath (absolute path to source file outside basePath). relativePath kept for structural compat but holds sentinel like context/<id>.

### 2026-02-18T21:37:22.080Z - Thought
Scope mapping: ~/.claude/CLAUDE.md → global; {git-root}/.claude/CLAUDE.md → project; ~/.claude/agents/*.md → global; {git-root}/.claude/agents/*.md → project; .claude/memory/agents/{name}/MEMORY.md at agent root → agent-project/agent-global. Stored in the graph.json/index.json of the resolved scope — loadMergedGraph() picks them up for free.

### 2026-02-18T21:37:34.391Z - Thought
New module: skills/memory/src/context/ with context-file-discovery.ts, context-file-indexer.ts, context-file-types.ts. Do NOT add to link.ts (507 lines, near 500-line warning). New EdgeType.GovernedBy = 'governed-by' for memory→context-file direction. EdgeType.Documents = 'documents' should also be formally added to enum (currently only in mermaid abbreviations).

### 2026-02-18T21:37:34.856Z - Thought
Critical: .claude/memory/agents/{name}/MEMORY.md is NOT a plugin memory file — it lives at the agent directory root, not in permanent/. syncMemories() already only scans permanent/ and temporary/ so currently safe, but must never be pulled in as a regular memory. Index it explicitly as a context-file node with kind=agent-memory-summary.

### 2026-02-18T21:37:35.254Z - Conclusion
Introduce MemoryType.ContextFile with new context/ module. Extend sync/rebuild to discover context files. Add read-only write guards. New index-context CLI command. 5-phase implementation: types → discovery/indexer → sync integration → mermaid/guards → CLI wiring.
