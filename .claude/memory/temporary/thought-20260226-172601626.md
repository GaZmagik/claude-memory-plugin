### 2026-02-26T17:26:07.988Z - Thought
GraphNode.type is string not MemoryType — this causes string literals like 'hub', 'rule', 'reminder' to be scattered across mermaid.ts and graph code instead of using the MemoryType enum. Changing this requires updating graph/structure.ts line 17 and all consumers.

### 2026-02-26T17:26:10.216Z - Thought
The type guard anti-pattern Object.values(Enum).includes(value as Enum) is used in 5 places (core/validation.ts lines 49,73,97 and think/validation.ts lines 44,51). The correct pattern is: typeof value === 'string' and (Object.values(Enum) as string[]).includes(value).
