Session restore process launching all three agents (memory-recall, memory-curator, check-gotchas) in parallel reduces total restoration time vs sequential execution. Agents operate with separate context budgets, enabling parallel work post-compaction. Fresh context window (~5% used) ideal for spawning agents without budget constraints.
