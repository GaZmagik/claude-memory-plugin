When fixing review findings, prioritise quick format/documentation fixes before architectural changes. This provides early momentum and validates review accuracy when tests immediately pass. Pattern: organize fixes by effort (5-30 mins → 2-4 hours → 4+ hours), tackle smallest first, commit batches to keep git history clean and reversible.
