User pivoted design during v1.3.0 exploration: meetings should be Accord's responsibility, not memory plugin's. This decision was made BEFORE specification phase, preventing wasted effort. Key insight: Early architectural validation with stakeholders prevents building the wrong thing. In this case, checking with user during exploration saved days of implementation. Pattern: Run architectural decisions through user before committing to spec.
