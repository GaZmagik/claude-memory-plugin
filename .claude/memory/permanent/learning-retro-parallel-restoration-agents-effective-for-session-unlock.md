Running memory-recall, memory-curator, and check-gotchas as background agents in parallel during /session-restore is efficient. Main session unlocks immediately while agents work. Three-agent pattern with approval key verification prevents race conditions. Consider expanding this pattern to other post-compact restoration tasks.
