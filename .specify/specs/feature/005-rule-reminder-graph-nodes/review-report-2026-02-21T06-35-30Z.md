### C2. Pervasive `as any` Casts Defeat Type Safety

**Severity:** CRITICAL (Type Safety)
**Expert:** Code Quality, TypeScript
**Files Affected:**
- `skills/memory/src/external/external-file-indexer.ts` (lines 99, 127, 163, 300-303)
- `skills/memory/src/maintenance/sync.ts` (lines 276, 392-393)
- `skills/memory/src/core/delete.ts` (line 143)

**Problem:**
```typescript
function createGraphNode(entry: ExternalFileEntry): GraphNode {
  return {
    id: unsafeAsMemoryId(entry.id),
    type,
    title: entry.title,
    scope: entry.scope,
    agent: entry.agentName,
  } as any;  // <-- Casting entire return value to any
}
```

**Root Cause:** `GraphNode` interface has all fields optional for backward compatibility, but external nodes populate all fields. The `as any` masks type mismatches.

**Impact:**
- Type errors in node construction silently swallowed
- If `GraphNode` gains stricter typing, issues won't be caught
- Defeats TypeScript's safety guarantees

**Recommended Fix:**
```typescript
// Better approach - use type narrowing
interface ExternalGraphNode extends GraphNode {
  title: string;
  scope: string;
  agent?: string;
}

function createGraphNode(entry: ExternalFileEntry): ExternalGraphNode {
  return {
    id: unsafeAsMemoryId(entry.id),
    type,
    title: entry.title,
    scope: entry.scope,
    agent: entry.agentName,
  };
}
```

**Estimated Effort:** 2-3 hours
**Priority:** 🔴 **HIGH**

### I2. Inefficient File System Operations - 6 stat() Calls Per File

**Severity:** MEDIUM (Performance)
**Expert:** Code Quality, Performance
**File:** `external-file-discovery.ts`, lines 256-293

**Problem:** Each file undergoes:
1. `fs.existsSync(filePath)` -- stat call #1
2. `resolveSymlink(filePath)` -- calls `fs.realpathSync` -- stat call #2
3. `fs.statSync(realPath)` -- stat call #3
4. `calculateContentHash(realPath)` -- calls `fs.statSync` + `readFileSync` -- stat calls #4-5
5. `getModifiedTime(realPath)` -- calls `fs.statSync` -- stat call #6

**Impact:** For 10 external files = 60 syscalls, all synchronous.

**Recommendation:** Refactor to call `fs.stat` once per file, passing the stats object downstream.

**Estimated Effort:** 1.5 hours
