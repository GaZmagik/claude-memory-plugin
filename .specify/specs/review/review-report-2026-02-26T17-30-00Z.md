## CRITICAL Findings

### C1. Directory protection bypass via command chaining [Security]
- **Files:** `hooks/src/memory/directory-protection.ts:80-101`, `hooks/pre-tool-use/enforce-memory-cli.ts:28-38`
- **Issue:** Allowlist patterns checked before blocklist. `cat /dev/null && rm -rf .claude/memory/` matches `cat` allowlist first and bypasses destructive command checks.
- **Fix:** Check blocklist patterns BEFORE allowlist, or reject commands with shell chaining operators (`&&`, `||`, `;`, `|`) when referencing `.claude/memory/`.

### C2. Missing `await` on `writeFileAtomic` in tag operations [Code Quality]
- **Files:** `skills/memory/src/core/tag.ts:107,227`
- **Issue:** `writeFileAtomic` returns `Promise<void>` but is called without `await`. File write is fire-and-forget; failures silently swallowed as unhandled rejections. Index updated before file write confirmed.
- **Fix:** Add `await` before both `writeFileAtomic` calls.

### C3. Graph edge queries are O(E) linear scans per node [Performance]
- **Files:** `skills/memory/src/graph/edges.ts:147-163,188-208`, `skills/memory/src/graph/traversal.ts:88-93,120-122,157-162`
- **Issue:** `getInboundEdges`, `getOutboundEdges`, `getAllEdgesForNode`, `getNeighbours` each scan all edges. Called per-node in BFS/DFS, making traversal O(NxE) instead of O(N+E). `hasNode` uses `Array.some()` — O(N) per call.
- **Fix:** Build adjacency list once before traversal loops. Use `Set` for node lookups.

### C4. Embedding cache loaded+saved on every single call [Performance]
- **Files:** `skills/memory/src/search/embedding.ts:158-188`
- **Issue:** `getEmbeddingForMemory` loads full cache from disk, adds one entry, saves full cache. Per auto-link operation: N sequential read-parse-write cycles on a multi-MB file.
- **Fix:** Pass loaded cache through call chain; save once at end.
